# Проект: Deutsch für Russen

Тренажёр немецкого языка для русскоязычных. Vite + React 19 + TypeScript, без бэкенда.

## Конвенции проекта

- **Ноль runtime-зависимостей кроме React.** Не добавлять react-router, zustand, UI-библиотеки —
  роутер и стор написаны вручную (`src/lib/router.ts`, `src/lib/progress.ts`).
- **Всё содержимое курса — в `src/data/`**, строго типизировано через `src/types.ts`. Логика — в `src/lib/`,
  экраны — в `src/views/`, примитивы — в `src/components/ui.tsx`.
- **Данные глаголов:** для слабых глаголов указывать только `stem` + `partizip2` (формы выводятся в
  `src/lib/conjugate.ts`); для сильных — массивы `praesens` и `praeteritum` из 6 элементов в порядке
  ich, du, er/sie/es, wir, ihr, sie/Sie.
- **Артикль — часть слова.** В лексике всегда заполнять `article` и `plural` для существительных;
  UI красит артикли: der — синий, die — розовый, das — зелёный.
- **Тексты интерфейса и комментарии — по-русски.** Немецкий только в учебном контенте.
- Стили — один файл `src/styles/global.css` с CSS-переменными в `:root`. Светлая тема.
- Проверка перед сдачей: `npm run typecheck && npm run build`.

## Статус

24 темы грамматики, 10 типов упражнений, SRS, прогресс/XP/серия.
