## Создан тренажёр немецкого языка «Deutsch für Russen»

**Задача:** React + TypeScript сайт для изучения немецкого с нуля русскоязычным: базовая лексика, фонетика,
грамматика, основные глаголы в контексте.

**Проект:** `/Users/dmitrii/Documents/hy4/german_verbs`

### Технические решения

- **Vite 8 + React 19 + TypeScript 5.9.** Ноль runtime-зависимостей кроме React.
- **Собственный хеш-роутер** (`src/lib/router.ts`) вместо react-router — сайт открывается откуда угодно,
  включая статику. Роуты: `/`, `/trainer`, `/alphabet`, `/phonetik`, `/wortschatz`, `/verben`, `/grammatik`,
  `/uebungen`, `/favoriten`, `/fortschritt`, `/einstellungen`. Параметры через query: `?deck=`, `?verb=`, `?topic=`.
- **Состояние прогресса** — свой store на `useSyncExternalStore` + localStorage (`src/lib/progress.ts`),
  ключ `deutsch-trainer-progress-v1`. Никакого бэкенда.
- **SRS** — упрощённый SM-2 (`src/lib/srs.ts`): интервалы 0/1/2/4/7/14/30/60/120 дней, ease 1.3–3.2,
  оценки «Забыл/Трудно/Хорошо/Легко». Слово считается освоенным при интервале ≥ 30 дней.
- **Озвучка** — Web Speech API (`src/lib/speech.ts`), выбор немецкого голоса и скорости в настройках.
- **Умлауты** — `ae/oe/ue/ss` засчитываются как `ä/ö/ü/ß` (`umlautVariants` в `src/lib/text.ts`), плюс панель
  быстрого ввода под полем.
- **Упражнения генерируются на лету** из данных (`src/lib/drills.ts`), 10 типов. Дистракторы берутся из того же
  пула с дедупликацией.

### Контент

- `src/data/alphabet.ts` — 30 знаков, IPA, русское приближение, пример, ловушка.
- `src/data/phonetics.ts` — 22 правила чтения + 8 минимальных пар.
- `src/data/vocabulary.ts` — 258 слов, 12 колод, артикль/плюраль/IPA/пример.
- `src/data/verbs.ts` — 75 глаголов; для слабых задаётся `stem` + `partizip2`, формы строятся в
  `src/lib/conjugate.ts`; для сильных — явные массивы из 6 форм (ich, du, er/sie/es, wir, ihr, sie/Sie).
- `src/data/grammar.ts` — 24 темы с таблицами, примерами, разделом «ловушки для русскоязычных» и привязкой
  к типам упражнений.
