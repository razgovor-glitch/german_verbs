# Deutsch für Russen — тренажёр немецкого языка

Интерактивный сайт для изучения немецкого с нуля человеком, который знает русский.
React + TypeScript + Vite. Без бэкенда: весь прогресс хранится в localStorage браузера.

## Что внутри

| Модуль | Содержание |
| --- | --- |
| **Алфавит** | 30 знаков (26 букв + ä ö ü ß), звук, транскрипция, примеры, тренировка на слух |
| **Фонетика** | 22 правила чтения с примерами и типичными ошибками русскоязычных + минимальные пары |
| **Лексика** | ~258 слов в 12 тематических колодах: артикль, множественное число, IPA, живое предложение |
| **Глаголы** | 75 глаголов с полным спряжением (Präsens, Präteritum, Perfekt), императивом, управлением и 3 примерами |
| **Грамматика** | 24 темы: артикли, падежи, порядок слов, времена, предлоги — с таблицами и разделом «ловушки» |
| **Упражнения** | 10 типов заданий: выбор перевода, набор на клавиатуре, артикли, плюрализация, спряжение, Perfekt, падежи, аудирование, порядок слов |
| **Тренажёр** | Интервальное повторение (упрощённый SM-2) по словам и глаголам |
| **Прогресс** | XP, уровень, серия дней, календарь активности, разбор проблемных карточек |

## Как запустить

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Сборка и локальный предпросмотр:

```bash
npm run build
npm run preview    # http://127.0.0.1:4173
```

Проверка типов:

```bash
npm run typecheck
```

## Технические решения

- **Ноль runtime-зависимостей** кроме React. Роутер — собственный хеш-роутер (`src/lib/router.ts`), поэтому сайт
  открывается откуда угодно, включая `file://` после сборки.
- **Озвучка** — Web Speech API (`src/lib/speech.ts`). Голос и скорость настраиваются; по умолчанию выбирается
  первый немецкий голос в системе.
- **Умлауты на клавиатуре.** Ввод `ae`, `oe`, `ue`, `ss` засчитывается как `ä`, `ö`, `ü`, `ß` (`src/lib/text.ts`).
  Плюс панель быстрого ввода символов под полем.
- **SRS** (`src/lib/srs.ts`) — интервалы 0/1/2/4/7/14/30/60/120 дней с коэффициентом лёгкости; оценка
  «Забыл / Трудно / Хорошо / Легко».
- **Генерация упражнений** (`src/lib/drills.ts`) — задания собираются из данных на лету, поэтому сессии не
  повторяются.

## Структура

```
src/
├── data/            содержимое курса (алфавит, фонетика, лексика, глаголы, грамматика)
├── lib/             движок: SRS, прогресс, спряжение, генератор упражнений, озвучка, роутер
├── components/      UI-примитивы и движок упражнений
├── views/           экраны по модулям
└── styles/          дизайн-токены и глобальные стили
```

## Как добавить своё слово или глагол

Лексика — `src/data/vocabulary.ts`, глаголы — `src/data/verbs.ts`. Оба файла строго типизированы
(`src/types.ts`), так что опечатка в структуре будет поймана на `npm run typecheck`.

Для слабых глаголов достаточно указать `stem` и `partizip2` — все шесть форм построятся автоматически
(`src/lib/conjugate.ts`). Для сильных форм укажите массивы `praesens` и `praeteritum` из шести элементов
в порядке: ich, du, er/sie/es, wir, ihr, sie/Sie.
